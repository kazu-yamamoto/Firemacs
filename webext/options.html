Firemacs

Emacs keybindings for Firefox. Changes apply to open pages when saved.

Keys look like C-f, M-f, C-M-f, j, SPC, DEL, up; a two-key sequence is separated by a space, as C-x u. Write C-M-, not M-C-. An empty key disables the command.

M- is C-[, and also ESC, Alt (Option) or Meta (Command) if checked below. Keys starting with C-x follow the prefix key.
